# gsm-dev-core-0.1 placeholder

Physical skeleton for the release specified by
`docs/05_dataset_release_spec.md`. The directories are intentionally empty:
their presence does not claim that generation, validation, Data Freeze Gate,
or Benchmark Readiness Gate has passed.

- `private/oracle/` — world, rules, reports, and observation plan.
- `private/eval/` — scenarios, queries, gold, proofs, splits, and validation.
- `public/operational/` — ledgers, narratives, artifacts, and branch variants.
- `public/documents/` — immutable raw snapshots and normalized revisions.
- `public/definitions/` — public benchmark definitions.
- `public/runtime_queries/` — runtime request templates.
- `public/snapshots/` — publication-prefix packages.
- `public/graph_inputs/` — Mode A and Mode B input manifests.
